# Simulador de Investimentos com Excel
Projeto desenvolvido em Excel como parte do desafio Santander - Excel com IA e Claude da DIO, com o objetivo de criar um simulador para controle e projeção de investimentos em Fundos de Investimento Imobiliário (FIIs).
A ferramenta utiliza recursos do Excel para realizar simulações financeiras e organizar informações relacionadas aos investimentos, permitindo visualizar projeções de patrimônio acumulado e dividendos mensais em diferentes cenários.

## Objetivo
Desenvolver, como exercício prático, uma ferramenta simulada em Excel para controle e projeção de investimentos em FIIs.
A planilha permite realizar simulações considerando diferentes valores de investimento, períodos e taxas de rendimento, proporcionando uma visão projetada da evolução do patrimônio e dos dividendos mensais.

## Funcionalidades
- Definição do valor de investimento mensal  
- Simulação de diferentes períodos de investimento  
- Projeção do patrimônio acumulado  
- Projeção de dividendos mensais  
- Simulação de diferentes cenários de investimento  
- Consideração do salário como referência para definição do investimento  
- Simulação de diferentes perfis de investidor  
- Distribuição dos investimentos entre diferentes tipos de FIIs  
- Organização dos dados por meio de tabelas de apoio
